Estructuras de datos utilizadas

Fundamento teórico-práctico aplicado en la arquitectura del Sistema de Biblioteca Inteligente

1. Listas Enlazadas (Linked Lists)

Administran dinámicamente el catálogo de libros y el padrón de usuarios mediante nodos enlazados por referencias (next), permitiendo inserciones y bajas sin desplazar bloques de memoria.

2. Colas (Queues - FIFO)

Gestionan las listas de espera de libros prestados bajo el principio First In, First Out, asegurando equidad y respeto estricto al orden en que cada usuario solicitó el ejemplar.

3. Pilas (Stacks - LIFO)

Almacenan el historial de operaciones bajo el principio Last In, First Out, colocando la transacción más reciente en el tope para auditorías y revisiones inmediatas.

4. Algoritmos de Búsqueda

Combinan Búsqueda Lineal sobre listas dinámicas y Búsqueda Binaria (O(log n)) sobre colecciones ordenadas para localizar libros y usuarios por múltiples atributos.

5. Algoritmos de Ordenamiento

Implementan QuickSort, Inserción y Burbuja para reorganizar registros por título (A-Z / Z-A), autor, ISBN, año de publicación y estado, facilitando tanto la lectura humana como las búsquedas binarias.

Conclusión del Proyecto

El desarrollo del Sistema de Biblioteca Inteligente demuestra cómo la aplicación práctica de listas enlazadas, colas (FIFO), pilas (LIFO), algoritmos de búsqueda y algoritmos de ordenamiento transforma y optimiza la gestión bibliotecaria. Estas estructuras permiten almacenar dinámicamente libros y usuarios sin desperdicio de memoria, garantizar turnos justos mediante listas de espera ordenadas, mantener auditorías cronológicas precisas de cada movimiento y recuperar información en tiempos mínimos, brindando una solución escalable, confiable y orientada a las necesidades reales de una institución educativa.
